# 叫不出名字的东西

> **Unknown Unknowns** · 独立开发者的扫盲词典。不是知识库，不是教程。

**在线版 → [elysianx138.github.io/unknown-unknowns](https://elysianx138.github.io/unknown-unknowns/)**（能搜、能标"没听过 / 说不清 / 会了"，标注存在你本地浏览器）

**你不知道一个词，就不会去搜它；不搜它，AI 也帮不了你 —— 因为 AI 只回答你问得出的问题。**

这个仓库只做一件事：把人从「不知道有这回事」推到「知道它叫 X」。深度不管，原理不讲，结论不给。

**扫盲 ≠ 学会。** 知道一个词存在、知道它在哪儿咬你、知道该搜什么，不等于会做。这一行不放在最前面，它就会长成一本没人读完的教材。

---

## 为什么是「词」，不是「知识」

- 内容本身没有价值。任何模型被问一句「独立开发者出海要注意什么」，都能给出比这里更全的答案。所以这里不解释、不论证、不复制文档。
- 唯一稀缺的是取舍：一个人、没钱、做 Web 游戏、面向海外 —— 哪 60 个词真的会咬到他，按什么顺序咬。
- **扫盲有终点。** 一个领域 60–80 个词就覆盖了大部分「第一次撞墙」。扫完就是扫完了，不用维护一个五年黑洞。

## 怎么用

1. 从头读一遍，拿笔划三类：**① 完全没听过 ② 听过但说不清它在管什么 ③ 已经会的**。
2. ① 超过 20 个 → 这份表对你有用；③ 超过一半 → 这一层你扫完了，该往下钻（比如「游戏出海」再扫一层）。
3. **别一个个拿去「详细问」AI。** 每个词只要三样东西：它管什么、什么时候撞上、去哪查。深度只留给你下周真要做的那一个。否则会问 65 个问题、读 65 段两千字回答，一个都不记得。

## 1｜第一次把它放到公网

| 词 | 它管什么 | 什么时候撞上 | 不知道会怎样 | 去哪查 | 和谁连着 |
|---|---|---|---|---|---|
| DNS / A 记录 / CNAME | 怎么把域名指到某台机器 | 换服务器、绑自定义域名 | 白屏或还跳旧地址，你先查两天代码 | `DNS A记录 CNAME 区别` | TTL、HTTPS 证书、CDN |
| TTL | 解析结果在别人机器上缓存多久 | 改完解析「没生效」 | 反复改来改去，越改越乱 | `DNS TTL 设置多少` | DNS、CDN |
| HTTPS / 证书链 | 加密 +「这站是真的」 | 上线第一天、证书 90 天到期 | 浏览器标「不安全」或全站打不开，你当是 bug | `证书链不完整的表现` | DNS、CDN |
| CORS / 同源策略 | 浏览器允许谁的页面调你的接口 | 前后端分域部署、接第三方 API | 本地全通，上线全 403，查一天后端 | `CORS 预检 报错` | 环境变量、CDN |
| 环境变量 / .env | 配置和代码分开，密钥不进仓库 | 第一次连数据库、第一次放 API key | 数据库密码跟着 git 历史永久公开 | `.env 不该提交 git` | 密钥泄露 / secret scanning |
| CDN / 强缓存 | 静态文件放哪儿、缓存多久 | 改了前端但用户还是旧版 | 用户说「没变化」，你怀疑人生 | `Cache-Control 强缓存 刷新` | TTL、HTTPS 证书、部署 |
| ICP 备案 | 国内域名 / 服务器的前置许可 | 哪天想面向国内 | 站点直接被拦，补办两三周 | `ICP 备案 流程 时间` | 分发渠道、版号 |

## 几个真会咬人的组合

单个词只是词汇。真正出事的是**两点之间**：你在第 3 组学到的「会话录屏」，会在第 5 组变成 GDPR 的雷。下面这几条线，是这份表里最容易真咬到人的：

- **会话录屏 → GDPR / COPPA**：录屏会录到用户输入，也录到小孩。你只是「想看看用户怎么操作」，实际上开始处理个人数据了。
- **UTM → 埋点 → 漏斗**：没有 UTM，你知道有人转化，但永远不知道是哪条渠道带来的。
- **.env → secret scanning → 成本告警**：密钥泄露不是「泄露」那一刻出事，是账单爆炸那一刻出事，中间往往差几周。
- **支付通道 → 风控冻结 → Chargeback**：收款顺利时不觉得，一旦冻结或拒付率超阈值，通道直接关，钱和生意一起停。
- **订阅 → churn → 留存**：做订阅的人不看 churn，就永远读不懂自己任何一份数据。
- **平台独家条款 → 分发渠道**：签的时候只有一个平台，等想上第二个才发现签的是排他。

## 怎么补

只收「真撞过」的词，不收「听说过很厉害」的概念。每条六个字段：**词 / 它管什么 / 什么时候撞上 / 不知道会怎样 / 去哪查 / 和谁连着**。

一条能进来的标准：如果一个人不知道这个词，他会不会**永远想不起来去搜它**？会，才是扫盲；不会，那是教程内容，不进这个表。

---

**共 65 个词 · 10 组 · 按「第一次撞上」的事件排，不按学科**

支付、税务、法律这三组的具体规则会变（尤其主体资格和税率），「它管什么」只写方向，结论一律以你搜到的官方页面为准 —— 这是它不腐烂的唯一办法。
